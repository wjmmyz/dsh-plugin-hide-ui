# @wjmmyz/dsh-plugin-hide-ui

[English](README.md) | 中文

一个 DeepSeek Harness 插件包（bundle），用来清掉 Web 界面上的两类干扰项：

- 左侧边栏全局面板列表里的 **插件（Plugins）** 入口；
- **内置 Agent 预设**（标准模式、PTC 模式、最小模式、创作者模式）：新会话的预设
  选择器、设置里的「Agent 预设」页面，以及会话标题旁的预设标签都不再显示它们。

你自己添加的自定义预设仍然可见。已经在运行内置预设的会话不受影响——插件只过滤
选择器显示的内容，不会从 Host 里删除预设声明。

## 改变了什么

| 位置 | 效果 |
|---|---|
| 左侧边栏 → 全局面板行 | 插件行消失。其他面板行、工作区/会话列表、新建会话、设置都不变。 |
| 新会话预设选择器 | 只列出非内置预设；没有自定义预设时整个控件不显示。 |
| 设置 → Agent 预设 | 「内置」分组消失；「自定义」分组及其创作者入口不变。 |
| 会话标题旁的预设标签 | 会话运行内置预设时不再渲染。 |

插件页面本身没有禁用，其他入口仍可打开它。只是安装了本插件后，侧边栏里不会有
插件这一行。

## 为什么用这两个机制

插件行是侧边栏唯一强制固定、不进「更多」菜单的可固定列表的面板行，所以无法通过
界面取消固定。本插件往同一个 `sidebar.panellist` 单元格注册自己的占用者，用一个
什么都不画的组件替换掉那一行的图标渲染。

预设名单由 Host 通过 `remote.agentPresets.list()` 提供给浏览器，所有预设界面都
通过同一个共享函数读取它。因此在插件启用期间包装这个方法，就能一次性在所有界面
隐藏内置条目，既不用刷新，也不会改动 Host 的预设声明。

## 安装

把插件包装进 DSH profile 后启用：

```sh
dsh plugin install @wjmmyz/dsh-plugin-hide-ui
```

或者在 Web 界面打开 **插件** → **添加插件**，填入包名或本地目录。重启一次应用以
加载浏览器端资源，然后新建会话查看效果。

## 关闭

在 **插件** 页面关掉开关或卸载即可。两条隐藏规则都注册为插件副作用，关闭后立即
恢复原生行为，不需要重启 Host，也不残留状态。

## 已知限制

- 侧边栏这条规则绑定的是内置面板 id `plugins`。如果未来的 DSH 版本给这个面板改了
  名字，该行会重新出现，需要更新本插件。
- 判定「内置预设」的条件是：id 为 `standard`、`ptc`、`minimal` 或 `cordis`，并且
  该声明没有自带 name。这正是内置预设的标记方式；用户自己声明、复用了这些 id 但
  写了自己 name 的预设会被当作自定义预设保留。
- 插件只影响浏览器界面。`dsh --dump-config`、命令行以及其他方式启动的会话不受影响。
