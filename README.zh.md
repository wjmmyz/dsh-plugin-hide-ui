# @wjmmyz/dsh-plugin-hide-ui

[English](README.md) | 中文

一个 DeepSeek Harness 插件包（bundle），用来清掉 Web 界面上的两类干扰项：

- 左侧边栏全局面板列表里的 **插件（Plugins）** 行；
- **内置 Agent 预设**（标准模式、PTC 模式、最小模式）：新会话的预设选择器、设置里的
  「Agent 预设」页面，以及这些界面共同读取的预设名单里都不再显示它们。

你自己添加的自定义预设仍然可见；复用了内置 id 但写了自己名字的预设声明也算自定义，
同样保留。已经在运行内置预设的会话不受影响——插件只过滤选择器显示的内容，不会从
Host 里删除预设声明。

## 改变了什么

| 位置 | 效果 |
|---|---|
| 左侧边栏 → 全局面板行 | 插件行消失。其他面板行、工作区/会话列表、新建会话、设置都不变。 |
| 新会话预设选择器 | 只列出非内置预设；没有可选项时整个控件不渲染。 |
| 设置 → Agent 预设 | 「内置」分组里的标准/PTC/最小模式卡片消失。 |
| 会话标题旁的预设标签 | 被过滤掉的内置预设没有显示名可用了，标题处会显示原始预设 id（例如 `standard`），而不是本地化名称。 |

**默认保留创作者模式。** 有两个内置入口靠「预设名单里有没有 `cordis`」来决定是否显示：
设置里的「让 Agent 帮我创建预设」按钮，以及插件页面的「让 Agent 创建插件」行。把它们
过滤掉会连带禁用这两个功能，所以默认保留。如果你希望连创作者模式一起隐藏，并在配置里
把 `keepCreatorEntries` 设为 `false`，请接受这两个入口会一同消失。

## 如何回到插件页面

本插件隐藏了平时打开 **插件** 页面的侧边栏行，请走另一条路：侧边栏面板列表最后有一个
**更多** 按钮（加号图标）。它的菜单里有 **浏览更多插件**，点开就是插件页面。启用或关闭
插件包（包括本插件自己）都在那里。

窗口变窄时侧边栏是抽屉，先从标题栏的侧边栏按钮打开；macOS 桌面端侧边栏完全隐藏时，用
窗口控件旁的侧边栏按钮。

## 安装

把插件包装进 DSH profile 后启用：

```sh
dsh plugin install @wjmmyz/dsh-plugin-hide-ui
```

或者在 Web 界面打开 **插件** → **添加插件**，填入包名或本地目录。重启一次应用以加载
浏览器端资源，然后新建会话查看效果。

## 配置

| 字段 | 默认值 | 含义 |
|---|---|---|
| `keepCreatorEntries` | `true` | 在预设名单中保留创作者模式，使设置里的创作者入口和插件页面的创建插件行继续可用。 |

## 关闭

在 **插件** 页面关掉开关或卸载即可（通过上面的 **更多** → **浏览更多插件** 进入）。所有
隐藏规则都注册为插件副作用，关闭后立即恢复原生行为，不需要重启 Host，也不残留状态。
关闭后刷新一次页面，让浏览器端那一半被卸载。

## 实现方式

插件行是侧边栏唯一强制固定、不进「更多」菜单可固定列表的面板行，所以无法通过界面取消
固定。本插件往同一个 `sidebar.panellist` 单元格注册自己的占用者，替换掉那一行的图标
渲染，并用一条限定作用域的规则把带标记的那一行折叠掉。

预设名单由 Host 通过 `remote.agentPresets.list()` 提供给浏览器，所有预设界面都通过同一个
共享函数读取它。插件在自身存活期间替换了这个方法的访问器，因此所有界面会同时看到过滤后
的名单，无需刷新，也不会改动 Host 的预设声明。

## 已知限制

- 侧边栏这条规则绑定内置面板 id `plugins` 和侧边栏的 `<nav>` 标记。如果未来的 DSH 版本
  改了其中任何一个，该行会重新出现；预设那条规则不受影响。
- 判定「内置预设」的条件是：id 为 `standard`、`ptc`、`minimal` 或 `cordis`，并且该声明
  没有自带 name。这正是内置预设的标记方式。
- 已经在运行被过滤预设的会话仍可继续使用，但标题处会退化成原始 id，设置里也无法再把它
  选为默认预设；请改选一个自定义预设作为默认。
- 插件只影响浏览器界面。`dsh --dump-config`、命令行以及其他方式启动的会话不受影响。
